# 🥤 LA CRUCEÑA DISTRIBUCIONES

Bienvenido a nuestro proyecto web oficial.

**LA CRUCEÑA DISTRIBUCIONES** es nuestro emprendimiento en Santa Cruz de la Sierra, Bolivia. Estamos reuniendo fondos para iniciar una pequeña fábrica de jugos y gaseosas con buena calidad y precios accesibles para toda nuestra gente.

---

## 🚀 Objetivo del proyecto

Crear una marca local de bebidas refrescantes producidas en nuestra ciudad, impulsando el crecimiento económico y ofreciendo productos accesibles para la comunidad.

Este proyecto nace del esfuerzo, la visión y el apoyo de personas que creen en este sueño.

---

## 💚 Cómo funciona

A través de esta página web las personas pueden:

- Conocer el proyecto
- Elegir paquetes promocionales de co-fundadores
- Realizar donaciones libres
- Enviar comprobante mediante WhatsApp
- Participar en la votación de etiquetas de productos

---

## 📦 Estructura del proyecto

- `index.html` → Página principal
- `paquetes.html` → Selección de paquetes promocionales
- `formulario.html` → Registro de datos y envío de donación
- `gracias.html` → Agradecimiento y votación de etiquetas
- `logo.png` → Identidad visual del proyecto
- `qr.png` → Código QR de pago
- Imágenes de productos → Referencias visuales
